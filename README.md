# ⚠️ Exception Handling

Exercício para praticar o tratamento de exceções em JavaScript, aplicando técnicas de captura e lançamento de erros, além de garantir a estabilidade do código com o uso de `try`, `catch` e `finally`.

## ✨ Demonstração

> O projeto visa a implementação de funções que utilizam o tratamento de erros para garantir que exceções sejam devidamente tratadas e não causem falhas na execução do programa.

## 💡 Sobre

Neste exercício, foi dado foco ao tratamento de exceções no JavaScript, utilizando os blocos `try`, `catch` e `finally` para garantir que o código continue funcionando corretamente, mesmo quando ocorrerem erros inesperados. A ênfase foi em identificar e capturar erros para que o sistema continue a execução sem falhas inesperadas.

## 🛠️ Habilidades desenvolvidas

- Tratamento de erros com `try`, `catch` e `finally`
- Lançamento de exceções personalizadas com `throw`
- Depuração e controle de fluxo com a captura de exceções

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
